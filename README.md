# 📌 Project Name: School Aid

## Description

School Aid is a web-based platform designed to enhance communication and academic collaboration between students and lecturers. It allows students to submit coursework, receive feedback, and stay updated on school activities through notifications.

---

## Key Features

* 📤 **Assignment Submission**
  Students can upload and submit their coursework or extra work to lecturers.

* 📝 **Lecturer Review System**
  Lecturers can review submitted work and provide feedback or marks.

* 🔔 **Notifications System**
  Students receive updates on assignments, feedback, and school activities.

* 📢 **Activity Posting**
  Students can post and share school-related activities and events.

* 👥 **User Interaction**
  Enables communication and engagement between students and lecturers.

## Installation Requirements

* Web browser (e.g., Chrome, Firefox)
* XAMPP / WAMP / LAMP server
* PHP 7.0+
* MySQL
* Localhost environment

---

## Project Structure

```
/school-aid                 - Main project folder
/school-aid/assets          - CSS, JavaScript, images
/school-aid/includes        - Database connection and reusable PHP files
/school-aid/pages           - Web pages (dashboard, login, etc.)
/school-aid/uploads         - Uploaded student assignments
/school-aid/database        - SQL files for database setup
```

---

## How to Run the Project

1. Install XAMPP or any local server.
2. Place the project folder in the `htdocs` directory.
3. Start Apache and MySQL from XAMPP.
4. Import the database file into phpMyAdmin.
5. Open your browser and go to:

   ```
   http://localhost/school-aid
   ```
